# Casa Clara

Controle financeiro local da casa: gastos fixos, cartões e metas de lazer e mercado. Os dados ficam no navegador.

```bash
npm install
npm run dev
```

Abra http://127.0.0.1:5173. O site publicado fica em https://sbozzola1-rgb.github.io/casa-clara/.

Cada navegador guarda a própria cópia. Use **Baixar cópia** na barra lateral para guardar um arquivo e **Restaurar** para trazer de volta, inclusive ao abrir o site publicado pela primeira vez.
