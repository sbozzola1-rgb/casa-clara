# Casa Clara

Controle financeiro local da casa: gastos fixos, cartões e metas de lazer e mercado. Os dados ficam no navegador.

```bash
npm install
npm run dev
```

Abra http://127.0.0.1:5173. O site publicado fica em https://sbozzola1-rgb.github.io/casa-clara/.

Os dois entram com a mesma senha. O que um lançar, o outro vê. **Baixar cópia** guarda um arquivo de reserva e **Restaurar** devolve esse arquivo para a casa.
